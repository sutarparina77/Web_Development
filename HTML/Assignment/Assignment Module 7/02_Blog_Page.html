About Semantic HTML

Semantic HTML refers to writing web markup using elements that clearly describe their meaning and purpose to both the browser and the developer. (header, article, nav): These elements explicitly declare their role. A browser immediately knows a nav contains navigation links, and an article holds astandalone piece of content.

Why Semantic HTML Matters:Improves Accessibility: Assistive software like screen readers use these landmarks to help visually impaired individuals navigate a page efficiently.

Author : Tim Berners-Lee
